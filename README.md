# Grades-Calculator

A simple **Java grades calculator** I made for my college modules to quickly work out a final mark when the grade is split between **CA (Continuous Assessment)** and an **Exam**. :contentReference[oaicite:1]{index=1}

## What it does
- Helps you estimate a final module grade using **CA vs Exam** weighting.
- Built as a small Java program (no frameworks).
